# Tales-Of-Faust
Este projeto foi desenvolvido a partir do estudo de caso de um jogo de masmorra infinita, também conhecido como dungeon crawler. 

O projeto atende às características solicitadas pelo discente, incluindo:
-exploração contínua da masmorra;
-ocorrência de um evento aleatório a cada andar, como o encontro com um monstro ou a descoberta de um baú do tesouro;
-restrição de uso de determinados itens conforme o nível do jogador.

Para executar o projeto, é necessário iniciar o arquivo Main.kt.
