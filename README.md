# Tales-Of-Faust
Este projeto, desenvolvido para a aula de Coding da UniNorte, consiste na criação de um Dungeon Crawler (DRPG). O jogador explora uma caverna em um ciclo de descida por andares, enfrentando eventos aleatórios, como combates e tesouros, que alteram seu HP e ouro. Uma lógica relacional define quais itens ele pode usar.
